# Benutzerverwaltung

Es gibt folgende Nutzertypen:

## Admin
Wird nicht über die normale UI angelegt. Wird nur bei Setup und manuell durch
andere Admins angelegt.


## Normaler Benutzer
Stammesmitglieder, die sich selbst für Fahrten anmelden können


## Eltern Nutzer
Eltern, die ihre Kinder (die können einen Account haben oder auch nicht) für die
Fahrt anmelden können. Die Frage ist, wie man die Verknüpfung Eltern-Kinder macht
